# AGENTS.md

## Project

Kids Sudoku PWA. Vanilla JS, no framework, no dependencies. Hosted on GitHub Pages.

## Architecture

```
index.html          - App shell, all screens
style.css           - All styles, responsive, kid-friendly design
sudoku.js           - Puzzle generator/solver (4x4, 6x6, 9x9)
sounds.js           - Web Audio API sound synthesis
app.js              - Application logic, state, UI rendering
build.js            - Cache-busting build script (Node.js)
sw.js               - Service Worker (source, overwritten by build)
manifest.json       - PWA manifest
docs/               - Built output served by GitHub Pages
```

## Conventions

- **Language:** All code, comments, commits in English. UI text in German.
- **Commits:** Conventional Commits (feat/fix/chore/docs).
- **Deploy:** Feature branch + PR + squash merge to main. GitHub Actions runs build and deploys to Pages.
- **Git identity:** ff@nodomain.cc (private project, not corporate).
- **No frameworks.** Keep it vanilla. No React, no Svelte, no build tools beyond the hash script.
- **No external dependencies.** Everything runs client-side with zero npm packages.
- **Sounds:** Synthesized via Web Audio API. No audio files.
- **State:** localStorage only. No backend (planned for later).

## Key Design Decisions

- Target audience: children aged 3 and 7. Big tap targets (min 48px), no text-heavy UI.
- Picture mode uses emoji symbols, not image files.
- Timer uses wall clock time, stars based on speed per mode.
- Puzzle generator guarantees unique solutions via backtracking + solution counting.
- Service Worker cache name derived from content hashes for automatic invalidation.

## Files NOT to edit

- `docs/*` - Generated by build.js, overwritten on every commit.
